# Sistema Financeiro

## Sobre o projeto 
O objetivo é gerenciar pessoas, contas bancárias, receitas e 
despesas por meio de uma interface web integrada a uma API em .NET.

## Tecnologias utilizadas
- React
- TypeScript
- .NET 8
- C#
- SQL Server
- CSS

## Funcionalidades
- Cadastro de pessoas
- Cadastro de contas
- Cadastro de receitas
- Cadastro de despesas
- Dashboard com resumo financeiro

## Como executar

### Front-end
-cd frontend
-npm install
-npm run dev

### Back-end
-cd backend
-dotnet watch run

## Estrutura do projeto
- Front-end: React + TypeScript
- Back-end: .NET 8 Web API
- Banco de dados: SQL Server
